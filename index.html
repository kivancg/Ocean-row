The camera changes by itself while you row. Tap the 🎥 button on the view to pick one yourself (keys 1–5, 0 = auto). In the simulator (for testing without the rower), press Space for each stroke.

Connect Google Maps (one time)

The 3D view is Google's Photorealistic 3D Maps, the same 3D world as Google Earth. Google requires a free key for it.

  1. Get a key. The quickest is Google's free Maps Demo Key (no credit card, daily limit). Or create one in Google Cloud with Maps JavaScript API turned on.
  2. Paste it below. It's saved in this browser, so you only do this once.
If it still fails
  1. Open it from a web address instead of the file. Run python ocean-row-bridge.py in the folder with this file, then open http://localhost:8000.
  2. In Google Cloud > Credentials, open the key and check "Application restrictions". Set it to None, or add http://localhost:8000/* under Websites.
  3. Make sure Maps JavaScript API is enabled for the project.
